## How To Run

1. install npm

2. download the zip code which is ''dist'' directory

3. unzip the zip code

4. change to dist

   * >  `cd your_path/dist`

5. install http-server

   * > `npm i http-server -g`

6. run

   * > `http-server -p 8000`

7. check the url on your browser

   * > http://localhost:8000
